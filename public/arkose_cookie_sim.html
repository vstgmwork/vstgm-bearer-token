Catchpoint setup

For this fixture, set the Request Settings Cookie override for the current host below, using the cookie name dem-request-id and a synthetic value.

The three controls use normal credential inclusion. The final POST opts out of browser-managed credentials. Check the server response for whether the Catchpoint override still reached it.

This exercises cookie delivery on a local same-origin fixture; it does not emulate the Arkose service, its cross-origin policies, or prove the cause of Chrome 151 behavior. Do not use a production allowlist cookie here.
